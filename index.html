See it in action

Sites as apps and games

Your start page is a launcher

Every bookmark is a tile on the start page. Open it as a site, as an app without the browser around it, or as a game in game mode.

Filter by sites, apps, games or your own tags, sort by hand, by name or by last opened, and lay it out as a grid or a list in three sizes.

Every bookmark keeps its own settings, from the user agent and dark mode to game mode, and closing an app or a game takes you back to the start page.

Game mode

Play browser games from itch.io and similar sites, with WebGL 2, gamepad and audio.

Game mode hides the browser and routes input directly to the page. Input maps let you map controls to keyboard keys, mouse or gamepad input, with an editor built in.

It can also cut the game out of the page, fit it pixel-perfectly to the screen and apply CRT, LCD or upscaling shaders.

Built for buttons

Gamepad and keyboard navigation

A virtual cursor on the stick or D-pad, Vimium-style link hints that label every link with the buttons or keys that open it, and an on-screen keyboard as a grid or a wheel.

Every browser action can be bound to a gamepad gesture or a keyboard shortcut, in the app, with tap, hold and chord.

Read in comfort

Made for small screens

Reader view strips pages down to their articles, even logged-in and dynamic ones.

Dark pages use sites' own dark themes, or force dark on sites that have none. Page zoom from 50% to 300% reflows the layout, per tab.

Ads and trackers are blocked at the network level with Brave's adblock-rust, EasyList and EasyPrivacy.

Install

Pick the package for your system. All builds, including nightlies, are on GitHub Releases and only there; gh attestation verify FILE --repo mxmgorin/retsurf confirms a file came from there.

OSPackageWhere it goes
PortMasterArkOS, dArkOS, EmuELEC, Knulli, muOS, ROCKNIX retsurf-portmaster.zip ports folder, e.g. /roms/ports/
OnionOSMiyoo Mini Plus and Mini Flip retsurf-onionos.zip App/Retsurf/ on the SD card
AlliumMiyoo Mini Plus and Mini Flip retsurf-allium.zip Apps/Retsurf.pak/ on the SD card
spruceOSMiyoo, TrimUI and Anbernic handhelds aarch64, Miyoo Mini root of the SD card
NextUI, NX ReduxTrimUI Smart Pro, Smart Pro S and Brick retsurf-nextui.zip root of the SD card
CrossMix-OSTrimUI Smart Pro retsurf-crossmix.zip root of the SD card
Android retsurf-android-arm64.apk sideload it
Linux x86_64, aarch64 unpack and run
Windows retsurf-windows-x86_64.zip unpack and run
macOS retsurf-macos-aarch64.dmg open it and run Retsurf.app
